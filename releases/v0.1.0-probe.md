First experimental build of XiaomiGpt, a Kotlin companion app for Xiaomi AI Glasses.

This is a **diagnostic pre-release**, not a working replacement for Xiao AI.

### Included

- Camera enumeration, preview, JPEG capture and manual photo sharing to the official ChatGPT app when supported.
- Bluetooth microphone recording and playback with audio-route checks.
- A read-only local Wi-Fi endpoint check.
- Foreground media/camera/assistant key diagnostics and an exportable report.

### Validation

- 3 unit tests passed.
- Android lint: 0 errors; 4 dependency-update warnings.
- Debug APK built successfully and its v2 signature verified.
- Not yet tested on M2442G1 hardware.

### Limitations

No automatic AI conversation, ChatGPT sign-in, custom glasses pairing, automatic photo import or background assistant activation. HyperConnect camera compatibility is still unverified.

Download `xiaomigpt-probe-v0.1.0.apk` and `SHA256SUMS.txt` below. The APK is a debug-signed test build.

Target setup: M2442G1, firmware 1.8.12.0, Xiaomi 15 Ultra, Android 16.

See the repository README for credits and `docs/PROBE_TEST_GUIDE_v1.md` for testing instructions.
