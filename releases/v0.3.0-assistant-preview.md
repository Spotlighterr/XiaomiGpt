Vietnamese support and a native Android assistant entry point. **Pre-release**.

### What changed

- Vietnamese is the default for a new language preference. Select **Tiếng Việt** or **English**; the selection controls local recognition, ChatGPT response instructions and offline Android TTS together.
- Download the Vietnamese recognition model once (34 MB / 32 MiB). Existing English model files remain available. A matching offline Vietnamese TTS voice must be installed on the phone.
- Added Android VoiceInteractionService / VoiceInteractionSessionService so system assistant invocations can launch XiaomiGpt without keeping its screen open beforehand.
- A setup status checks whether Android selected the native service. The **Thử gọi qua trợ lý Android** button tests that route explicitly.
- An activation journal distinguishes app-generated test sessions, other system sessions, assist intents and observed foreground keys. Copy/clear actions include no conversation text, account details or credentials.
- A brief ready cue is attempted on the selected communication route. Duplicate activation events are debounced. The model used for a turn is remembered for that account.

### Test in this order

1. Install over the previous APK without clearing data. Keep the existing ChatGPT account/model.
2. Select **Tiếng Việt**, download its recognition model, and install an offline Vietnamese voice through **Cài giọng đọc Tiếng Việt / English**. Try a short in-app Vietnamese question first.
3. Tap **Đặt XiaomiGpt làm trợ lý mặc định** and select XiaomiGpt. If selected in an older build, reselect it in Android assistant settings. Check that the status says the XiaomiGpt service is selected.
4. Tap **Thử gọi qua trợ lý Android**. This is an app test, not proof that the glasses gesture works.
5. Return to the home screen with the phone **unlocked** and try the glasses' assistant gesture. If Xiao AI still responds, return to XiaomiGpt and copy **Nhật ký gọi trợ lý**, noting whether XiaomiGpt opened.

### Boundaries

The user confirmed that 0.2.1 connects and returns an assistant response. Vietnamese quality, native assistant binding on HyperOS and the actual glasses gesture remain unverified on hardware here.

This implements Android's assistant entry point; it does not reprogram a gesture consumed inside the glasses. Locked/screen-off conversation is not supported. Once a turn is active, leaving the assistant screen still cancels it. No wake word or always-on microphone. Camera support remains deferred.
