First voice-assistant preview. This is a **pre-release**, not a stable release.

### Included

- Official browser-based **Continue with ChatGPT**, protected local account storage, session refresh and sign-out.
- Model choices from the signed-in account, with ChatGPT plan-use consent and usage-management link.
- English speech recognition on the phone using Vosk. Download the English model once (40 MB).
- Short spoken ChatGPT replies through the Bluetooth headset using an offline Android English TTS voice.
- In-memory conversational context, typed-question fallback and explicit Stop.
- Android default-assistant selection and foreground assistant/headset-key handling for device testing.
- The existing connection/camera diagnostics remain accessible separately.
- MIT license for the project; third-party speech notices included.

### Test in this order

1. Install the APK and open XiaomiGpt.
2. Continue with ChatGPT in the system browser, authorize plan usage and return to the app. Wait for the model list.
3. Download the English recognition model, allow Bluetooth/microphone permissions and select the glasses if several headsets are connected.
4. Tap **Nói với trợ lý**, wait for the listening message, and ask a short English question. Check the transcript and listen for the reply.
5. If English speech output is missing, install an offline English voice using the app's TTS settings button.

### Known limits

This build implements ChatGPT plan inference with local speech processing; it does not embed ChatGPT Voice. Account eligibility and granted permissions determine access. No live account authorization or full conversation has been verified here.

Keep the assistant screen open: leaving it or locking the screen cancels the turn. No wake word or background listening. The Xiaomi temple gesture may still invoke Xiao AI; remapping has not been established. Android default-assistant activation on HyperOS also needs testing.

**Camera access remains unresolved.** No automatic glasses-photo import or independent Xiaomi pairing is included.

The user confirmed audio works in the earlier probe. This new assistant still needs end-to-end testing on the actual glasses and phone. The APK is debug-signed with the same project key as the previous probes.
