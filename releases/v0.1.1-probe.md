Usability update based on the first Xiaomi AI Glasses device feedback.

### Changes

- A simpler home screen for Bluetooth audio, microphone testing and glasses-camera status.
- Step-by-step microphone recording and playback, an audio-level indicator and a separate listener confirmation.
- Camera, Wi-Fi IP and key diagnostics are now under a collapsed Advanced section.
- Permissions are requested when needed; granting microphone access continues the requested test.
- Corrected HyperConnect guidance: it is not a universal Control Center toggle, and support in this app is unverified.

### Still experimental

Glasses-camera access is unresolved. This build does not implement independent Xiaomi pairing, automatic photo import, ChatGPT sign-in or AI conversations.

Initial user feedback reports Bluetooth audio availability, but microphone success remains unconfirmed until the route check and playback are verified. This update has not yet been tested on the user's glasses.

The APK is debug-signed with the same project key as v0.1.0. See `docs/PROBE_TEST_GUIDE_v2.md` for the short testing flow.

Validation: 7 unit tests passed, Android lint reported 0 errors and 4 dependency-update warnings, and the debug APK built successfully. Physical-device validation of this update is pending.
